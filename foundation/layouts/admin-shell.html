Contact Information

Centralized WhatsApp, phone, email, address, working hours, and public inquiry triage (`contact_inquiries` + `website_settings`).

Awaiting Backend Integration

Updates here dynamically update public `wa.me`, `tel:`, `mailto:`, header, and footer links across the website.

SEO Settings

Global & per-language titles, meta descriptions, Open Graph tags, social sharing images, canonical URLs, sitemap, and robots configuration.

Awaiting Backend Integration

Backed by `seo-meta.mjs` patterns and `website_settings` (`seo_global`).

User Management

View users, create authorized accounts, edit profiles, activate/deactivate accounts, assign roles, and review `security_events` activity.

Awaiting Backend Integration

Requires server-side `users.*` RBAC checks and protection preventing non-`super_admin` modification of `super_admin` accounts.

Roles & Permissions

Manage `super_admin`, `admin`, `editor`, and optional project-specific roles (`roles` + `role_permissions`).

Awaiting Backend Integration

Permissions defined in `config/rbac.json` must always be enforced on the backend.
