# Optional Module: Corporate & Professional Services

Activate for corporate headquarters, consulting firms, legal/engineering practices, and B2B service companies.

## Core Entities (Additive Tables When Activated)

- `services` + `service_translations`: Service offerings, scope, deliverables, icon/banner media, multilingual SEO.
- `portfolio_projects` + `portfolio_project_translations`: Case studies, client sector (anonymized when NDA applies), outcomes, media gallery.
- `team_members` + `team_member_translations`: Leadership/team profiles, title, bio, portrait media, display order.
- `testimonials` + `testimonial_translations`: Verified client quotes, organization, role, approval/visibility toggle (only publish real approved testimonials).
- `service_inquiries`: Requested service, organization, message, status.

## Admin Capabilities

- Organize service pages, portfolio case studies, leadership profiles, and real verified testimonials across all 6 languages.
- Manage corporate consultation inquiries with spam/rate-limit protection.
