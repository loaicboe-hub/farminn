# Optional Module: Tourism & Travel

Activate only for tourism agencies, tour operators, and destination management companies.

## Core Entities (Additive Tables When Activated)

- `destinations` + `destination_translations`: Regions/cities, gallery media, seasonal highlights, multilingual SEO.
- `tours` + `tour_translations`: Tour/package titles, duration, itinerary JSON blocks, inclusions/exclusions, starting price display (informational, not e-commerce checkout), visibility.
- `travel_inquiries`: Inquiry type (`booking_inquiry` | `custom_travel_request`), selected tour/destination, preferred travel dates, traveler count, contact info, status.

## Admin Capabilities

- Create/edit destinations and tour packages across all 6 languages.
- Track missing/unverified translations per tour/destination.
- Manage booking inquiries and custom travel requests securely.
